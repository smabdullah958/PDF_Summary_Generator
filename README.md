# PDF_Summary_Generator

📄 **AI Powered PDF Summary Generator**
An AI-powered web application that allows users to upload a PDF file and generate an intelligent summary using a Large Language Model (LLM).
The project focuses on simplicity, speed, and multilingual support.

**Project Overview**

The AI Powered PDF Summary Generator enables users to:

Upload a PDF document
Generate a summary using AI
Choose different summary formats
Translate summaries into multiple languages
This project is being built as a learning + portfolio project to explore Next.js full-stack capabilities and LLM integration.

**Features**

Upload PDF files

AI-generated summaries

Summary format options:

Paragraph format

Bullet points

Multi-language support:

English

Urdu

Pashto

Fast and responsive UI

Secure API key handling (LLM called from backend)


**Tech Stack**

Frontend

Next.js

Tailwind CSS

Backend

Node.js

PDF parsing library

LLM API (Gemini)
No Database (Initial)
No authentication
No data persistence
Focused on real-time processing
